# Little Layers

A relaxing, mobile-first paper-cut shadowbox creator. Each shape is a separate editable layer.

## First playable prototype

- Add hills, mountains, forests, waves, clouds and stars.
- Tap artwork to select a layer; drag it to reposition.
- Change paper color and perceived depth; reorder or delete layers.
- Choose between Sunset, Twilight, Daybreak and Sea Glass palettes.
- Realistic SVG paper shadows and optional gentle motion.
- Undo, autosave in browser storage, export 1200 × 1500 PNG.
- Download an editable JSON project backup and reopen it later.

No installation, AI account or paid API required.

## Publish through GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set **main** and **/(root)**, then Save.
4. After Pages reports the site published, visit **https://dstancomb3.github.io/Little-Layers/**.

## Notes

Projects autosave on the current browser only. Export a JSON project backup before clearing browser data. Animation is a preview, not included in static PNG export. Touch and browser functionality must be verified on a real phone.
